This is the reading the code already shipped (SQ-180), so **no runtime-behaviour change** — the amendment makes the spec match the audited code. Options (b) "emit event, return `Ok` without arming" and (c) "`on_finalize`-style emit" rejected: (b) makes a *refused* governance action report success, weakening fail-static (R-7); (c) adds machinery for no gain. `NavFloorUnmet` is **not** a frozen 02 §6 surface — 02 §6 lists it not-in-ingest, treasury-owned per 08 §1.4 — so `INTEGRATION_CONTRACT_VERSION` stays **6** (no bump, 02 untouched).
