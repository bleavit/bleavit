## Item

**FE-P7: native ANT n-of-m does not exist, and the platform it lives on moved from AO to Solana**

## Spec ref

12 §4.2, §1.4, §2.2; 10 §12; 00 D-16; 14 TH-39

## Status

**resolved 2026-08-07, negative, against published program source**

## Result

12 §4.2 makes 3-of-5 native ANT control the primary option, conditional on `[VERIFY ANT n-of-m controller capability]`. **The answer is no, and it is a property of the program rather than of any client.** `ar-io/ar-io-ant-process`, `src/common/utils.lua`: `assertHasPermission(from)` loops `Controllers` with `ipairs` and returns on the first match, then returns for `Owner == from`, then for `ao.env.Process.Id == from`. `assertHasRecordPermission` adds a balance holder and the per-record owner on the same any-one basis. Nothing accumulates approvals. A controller list is an **access-control list**, so it is 1-of-m, and adding controllers widens custody instead of splitting it. That is the opposite of what D-16 asks for. **The larger finding was not in the question.** That repository carries the notice *"This repository was archived by the owner on Jun 9, 2026. It is now read-only."* and its README states *"The AR.IO smart contracts have migrated from AO to Solana. All smart contract code now lives at ar-io/ar-io-solana-contracts."* The ar.io documentation now reads *"the registry is managed on Solana by the `ario-arns` program"*, and `ario-ant` ships as *"Arweave Name Token (ANT) as a Metaplex Core NFT with Attributes plugin, undername records, controller ACL"* — an ACL again. Program upgrades there use an "AR.IO Squads multisig", which governs the program and not a name. **Consequences.** 12 §4.2's primary option is withdrawn, so the threshold ceremony is the only path and D-16's launch block now has one way to be satisfied instead of two. Data upload is unaffected, because bundles still go to Arweave through Turbo and §1.2's two-pass flow is untouched. Name control is what moved, so every controller address, `setRecord` call and threshold-compatibility claim in 12 must be re-derived. Raised as **SQ-940**.
