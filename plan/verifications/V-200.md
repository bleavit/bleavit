## Item

**A local helper was asserting finality rather than establishing it, in four modules, and no gate could see it**

## Spec ref

10 §2.1, §2.2; INV-FE-1, INV-FE-9, INV-FE-12; `app/tools/check-provenance-mints.ts`

## Status

**measured 2026-08-06** (6 mutants, 0 survived)

## Result

Four reader modules each carried a private copy of `const finalized = <T,>(value: T): Verified<T> => ({ value, status: { kind: 'verified-finalized', chain: at.chain, … } })`, covering **17 call sites**. Eleven were honest; **six were not**, in the two shapes that matter. **Manufactured on a failure path:** `chain-reads.ts` badged `0` and `'unknown'` when the epoch decode failed, `funding-reads.ts` badged `0n` on both legs when a balance record did not decode, and `boot.tsx` badged `0`/`'connecting…'`/`0` `verified-best` at chain `0x`, block `0x`, height 0 before any read had happened. **Caller-supplied:** `review.tsx` assembled a `verified-finalized` badge out of a `Clamped<bigint>` and a `refreshedAt: FinalizedBlockRef` that arrived as two unrelated props, so a clamp computed at one block could be badged at another. **`chain-reads.ts` contradicted itself in one object literal** — `epoch` and `phaseLabel` took a badged fallback while `phaseFlags`, three lines down, chose `undefined` for the identical decode failure — and carried a comment defending the badge on the grounds that the sibling `undecodable` array *"is what says the number is not to be believed"*. **Why nothing caught it, measured rather than reasoned:** `check:casts` matches `as Finalized<…>` and type predicates, and there is no assertion here; `check:render-provenance` rule B matches an object literal whose `status` initializer is a `.status` **access**, and this one is written out field by field; the depcruise rule matches `@bleavit/chain-client/testing`, which the shape never imports. Six mutants reintroducing the pattern (the original helper, the sentinel, the caller-supplied stamp, a folded `const` naming the discriminant, a `{ kind, … }` shorthand, and a mint in `packages/ui`) **all compile under `tsc -b`, and all three incumbent gates are green on every one**. The new gate catches all six. **The deeper fact the gate is built on:** `Verified<T>` deliberately carries no brand, and `ProvenanceBadge` renders off `status.kind` — so the discriminant *is* the claim, and `Finalized<T>`'s brand never governed what a user sees. The rule therefore matches the discriminant position of a closed union, which is complete (no member can be built without it) and quiet (a `.kind` comparison, a `switch` arm, `local-index`'s same-spelled `BodyProvenance` tag and the type declarations are not property assignments in an object literal, so no exemption is needed for any of them).
