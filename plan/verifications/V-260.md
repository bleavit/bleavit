## Item

Can `LocalIndex` be constructed in production — does this release pin a parachain genesis hash?

## Spec ref

10 §7, §3.1; 12 §1.1

## Status

✅ Measured (2026-08-07)

## Result

**No, and every neighbouring pin is null too.** `app/tools/release/sources/release-sources.json` `chainIdentity` carries `genesisHashes.para: null`, `genesisHashes.relay: null` and both `chainSpecHashes` null, with its own note stating *"a null is a readiness blocker, never a default"* and a `_hash_gate` recording that no production chain exists. 10 §7 names the index database `futarchy@<paraGenesisHash-prefix8>` and `LocalIndex` takes that hash as a required, validated argument with no default, so there is nothing to open an index for. F25's boot path therefore reaches `not-opened` in production, and the claim is bound to the file by `tests/analysis/index-disclosure.test.ts` — the assertion fails the day a genesis is pinned, so the wiring cannot stay unreached by inertia
