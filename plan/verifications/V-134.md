**The first 76 test/tool files type-check to 1,974 errors — and the first five migrated turned up two malformed fixtures**

## Spec ref

— (workflow)

## Status

**measured 2026-08-05**

## Result

Measured rather than estimated, by running `tsc --checkJs` over the existing tree before renaming anything: **1,974** errors, falling to **1,499** once `@types/node` was added (it was not installed at all). The migration's value showed up immediately in the first five files: `planImport({ bytes: 1_000 }, …)` omitted the **required** `rows` field — a fixture that was not a `QuotaState` at all, in a test written hours earlier and passing, because `planImport` happens to read only `bytes`; and a `Provider` fixture whose `kind` widened to `string` instead of the `'snapshot' | 'indexer'` union. Neither changed behaviour, and neither could have been caught by running the tests. Also pinned a distinction `exactOptionalPropertyTypes` exposes and prose would not: `{ ...VENDOR, maxUrlChars: undefined }` is **not** an absent property, and only production's choice of `=== undefined` over an `in` check made the fixture accidentally correct
