## Item

**All six §11.8 gaps closed; F17's remaining blockers are the two external ones it always named**

## Spec ref

11 §11.8.1–§11.8.6

## Status

**verified 2026-08-05**

## Result

V-117's read found six requirements unbuilt. All six now are. The last two: §11.8.6's ingest filter **binds the pallet**, because `pallet-registry` and `pallet-oracle` both publish `WindowAcknowledged`/`WindowExtended` — with *different fields* — so a filter matching the variant name compiles, runs, and silently ingests events about a different sub-game; the visible symptom is a registry countdown that moves when an **oracle** watchtower extends an **oracle** round, and a challenger who trusted it misses their window. Checked in **both directions**, because one alone is weaker than it looks: the pallet must match, **and** the body must not carry `component`/`round`, since a right-label wrong-body event is the same failure by another route and checking only the label trusts the labeller. And §11.8.1's `recompute_proof` makes *"never submit a proof the client's own recomputation contradicts"* structural — `RecomputedProof` is branded with one mint site and `RecomputeSubmission` requires one, so a contradicted proof cannot be assembled into a submission; the **evaluator is a required argument** (an optional one defaults the recomputation off — `FE-HANDOFF-010`'s shape for the third time), and a **non-deterministic component is refused before the evaluator runs**, because a disagreement there looks like fraud when it is really a component nobody promised would reproduce. F17's genuinely remaining blockers are **FE-P10** (an empirical in-browser measurement, R-2 forbids resolving by assumption) and **SQ-564** (a 02 §7 contract addition needing joint sign-off) — both external, both already named
