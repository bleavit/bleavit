## Result

The row worth keeping is *why a correct-looking repair was still wrong*: V-170 replaced a wrong count with a right one and then treated it as the whole population, which it never was. **Hosted books are canonical ingest, not somebody else's traffic** — 11 §11.2a (normative, SQ-571) states *"the canonical client serves external books"*, 02 §5 states `Traded`/`Observed` with no domain filter, and `Pallet::ensure_trade_admissible` admits `BookKind::External` on `ExternalQuestionStatus::trading_open`, so `crank_observe` and `buy` emit on the identical paths. **The fill ceiling is a sum over partitions**: `classifier::is_external_client_call` → `market_call_targets_external_book` routes a fill by **book kind**, `Welfare::side_fits` checks only that side's capacity, and the joint constraint is `before + amount ≤ max_block` — so both are consumable in one block. Measured live rather than derived (the V-170 lesson applied to itself): primary `(1.5e12, 7,864,320)` = **70** fills, external `(5e11, 2,621,440)` = **23**, `max_block` `(2e12, 10,485,760)` = **93**, with 70 + 23 = 93 exactly. The external quota is `Operational.reserved` = 25 % of the block on both dimensions. **The hosted duty cycle is 1, not 13/21**: a question is `Open` for a window up to `svc.max_window` = 302,400 blocks = `epoch.length` (13 §1), giving 1,440 rows/book/day against a primary book's 891.43 — independently confirmed by 13 §2's fee-floor derivation, which counts `2 · ceil(svc.max_window / mkt.obs_interval)` = 2 × 30,240 cranks per question. **Population**: `MaxLiveExternalMarkets` = `min(2·svc.max_live, 128)` (`configs.rs`), `svc.max_live` = 16 provisional with registry max **64**, so 128 hosted books are reachable by two PARAM amendments and the planning figure is **159** books. Consequences: `Traded` 1,008,000 → **1,339,200 rows/day**; desktop events share 8.9 h → **6.7 h**; desktop raw depth 54 d → **7.1 d**; hourly candles 672 d → **131 d**. **What the gate could not see**: `check-frontend-budgets.py` re-derived every cell from the owning sources and still agreed, because a checker that models one partition cannot notice a second — the anti-vacuity floor counted cells, not coverage.
