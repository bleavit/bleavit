## Item

`ExecutionGuard.PendingUpgrade`'s field set

## Spec ref

11 §11.8.4 step 1; 02 §7.4

## Status

✅ Corrected

## Result

Doc 11 spelled `PendingUpgrade { hash, authorized_at, applicable_at }`. The stored type carries a **fourth** field: measured from metadata, `execution_guard_core::PendingUpgrade{hash:[u8;32],authorized_at:u32,applicable_at:u32,target_spec_version:u32}`. A three-field spelling is not wrong about what it names, but it is the document a client implements from, and the missing field is the one that says *which runtime this authorization is for*. Corrected with the v28 freeze
