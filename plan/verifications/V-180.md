## Item

**CI can run Lighthouse without downloading a browser**

## Spec ref

`.github/workflows/ci.yml` (app job); 10 §9.4

## Status

**verified 2026-08-06** against the `actions/runner-images` manifest

## Result

The question that decides whether the render row is gateable at all, asked before the dependency was added rather than after. The Ubuntu 24.04 image — what `ubuntu-latest` resolves to — ships **Google Chrome 150.0.7871.128** and **Chromium 150.0.7871.0** preinstalled, so `chrome-launcher` finds one on `PATH` and no Puppeteer/Playwright browser download is needed; the gate stays `--frozen-lockfile`-clean and adds no network step. The gate **fails rather than skips** when no browser can be started, because a skipped measurement is an unenforced budget, and `CHROME_PATH` overrides the search for workstations without a system Chrome (this one has none; the local runs were taken against a Playwright-cached Chromium 149)
