## Item

**Six suites already passed by running nothing, and every further migrated slice would have joined them**

## Spec ref

15 §4.8

## Status

**measured and gated 2026-08-05**

## Result

Each `app/tests/*/package.json` declared `"test": "node --test *.test.js"`. In a directory migrated to TypeScript that glob matches no file, and Node reports `# tests 0` with **exit 0** — measured directly in `tests/receipts`, not inferred. Six were already in that state (`contexts`, `firewall`, `llm-handoff`, `mock-runtime`, `providers`, `receipts`), i.e. exactly the six already migrated. Nothing went red because CI does not use these scripts: the root `test:<suite>` scripts go through `tools/run-suite.ts`, which globs `{js,ts}` — so the silent zero was reserved for a developer running the package's own script, which is the worst audience for it. Fixed to bare `node --test`, whose discovery covers `.js` and `.ts` alike and therefore cannot drift from the files again (verified it finds the suite in `tests/firewall` **without** picking up the 18-file negative-compilation corpus in `fixtures/`, and `tests/release` keeps `--test-concurrency=1`, whose absence tears `dist/`). Two gates added to `tools/ci/tests/test_workflow_wiring.py` rather than trusting the repair: no suite script may select by extension, and every suite declaring a `test` script must hold a discoverable test file — the second because the first is satisfied by an empty directory, which is the same silent zero from the other side. Both mutation-proven.
