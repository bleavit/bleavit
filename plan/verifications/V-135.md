## Item

**The generated-artifact line count, measured three times because two estimates were wrong**

## Spec ref

02 §11; 10 §5.1

## Status

**measured and partly fixed 2026-08-05**

## Result

PR #228 was 66,345 added lines of which **63,817 (96 %) was machine-generated** and 2,528 hand-written; PR #234 is 73,080 of which 32,805 is generated. Two corrections worth recording because each was a confident wrong number. (1) **`.gitattributes` `-diff` does not reduce GitHub's `+/-` counters** — it collapses the *display* and excludes from language stats only. `git diff --shortstat` drops to 43,388 and GitHub still reports 73,080; the gap is exactly `papi-descriptors` + the chainHead rewrite, so a reported \"-42 %\" was really about -1,600. (2) **The `.d.ts` compaction ceiling is not -97 %.** That estimate counted declaration lines and ignored comments: after collapsing, **77 % of the remaining 56,449 lines are doc comments** carrying the on-chain pallet documentation. The TypeScript printer makes the files 14 % *larger*, and prettier's `--print-width` alone changes nothing because it **preserves an object's original line breaks** — `--object-wrap collapse` is what actually folds a type onto one line. Landed: chainHead transcripts 31,156 → 281 (-99 %, and it would have cut PR #228 by ~26,600), descriptors 64,391 → 56,449 (-12 %). Not taken: stripping the doc comments would reach ~12,714 (-80 %) and costs a developer the hover documentation for every chain surface, which is the wrong trade in solvency-critical code
