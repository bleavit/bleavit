## Item

**Three CI-fatal dependency-cruiser rules could never fire**

## Spec ref

10 §10.1; D-21; INV-FE-6

## Status

found + fixed 2026-08-03 (F3)

## Result

`only-platform-touches-host-sdks`, `no-network-primitive-in-handoff` and the new chain-connection rule all matched `to: { path: 'node_modules/(…)' }`. dependency-cruiser records an external specifier it cannot resolve — one that is not installed, or whose `exports` map hides its subpaths from enhanced-resolve — **verbatim as the bare specifier** with `couldNotResolve: true`, never as a `node_modules/` path. Proven by injecting `import 'ws';` into a handoff package: zero errors, silently. So D-21's *"the handoff packages contain no network primitive at all"* had a module-import half that was decoration, and the source-level half its comment credits **does not exist yet** (the handoff packages are stubs; that gate is F17/F18). Fixed with a shared `EXTERNAL()` matcher covering both forms (`app/tools/depcruise-external.cjs`), all five injections now proven to fire, and a permanent witness module (`tests/depcruise-witness/forbidden-external.ts`) that imports the production matcher rather than restating it — the third time in this repository that a green checker turned out to be incapable of failing, after F0's dependency-cruiser and F2's whitelist.
