## Item

**The render-provenance gate could not see the defect it exists to prevent, and the measurement said so before the rule was written**

## Spec ref

10 §2.1; INV-FE-9; `app/tools/check-render-provenance.ts`

## Status

**measured 2026-08-06**

## Result

Codex's P1 on #248 was a `Verified<number>` interpolated into a sentence by a helper, with the returned `string` rendered as a JSX child. `check:render-provenance` is type-aware and CI-fatal and it passed, for **two independent reasons** — worth separating, because fixing either alone leaves the hole open. **(1)** At the render site there is no `Verified<T>` to type-test: the helper returns a plain `string`, so the provenance is gone one call frame before the gate looks. **(2)** The helper lived in `oracle-reporting.ts`, and the scan filtered `if (!rel.endsWith('.tsx')) continue` — the file was **never opened by any version of this gate**. Rule C now flags a `Verified<T>.value` unwrapped inside a `string`-returning function, and the scan reads `.ts` as well. **Feasibility measured before building, because a rule that fires on correct code gets switched off**: across the five rendering projects there are **125** `Verified<T>.value` unwraps in 52 files, and **0** sit inside a string-returning function on the repaired tree; restoring the pre-fix file from `0bb46b40` yields **exactly 1** — the defect. One true positive, zero false positives, and both numbers are in the rule's own doc comment so a later widening has to re-argue them. The witness gained a second file (`witness-model.ts`, no JSX in it at all) because a `.tsx`-only fixture would prove rule C while leaving the filter widening unproven, and it now **refuses to pass if any rule has no expectation** — a fixture that lost its only rule-C case would otherwise still report success. The general lesson is about where a checker's *coverage boundary* sits rather than about its logic: this gate's rules were correct while its file filter and its notion of "display position" were both narrower than the property it claims to enforce, which is V-161's shape (`.ts` that merely *runs* is unchecked) one level up
