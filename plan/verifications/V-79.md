## Item

**The 13 frozen `FutarchyApi` signatures were the one part of the critical surface no gate compared**

## Spec ref

02 §3; 10 §5.1

## Status

verified 2026-08-03, closed

## Result

207 of `surface-manifest.json`'s 222 entries carry a frozen `layout`; the 13 `runtime_api` entries carried none, so they were checked for *presence* only and a changed return type would have passed both the per-commit feed gate and the fixture recorder. 02 §3 is explicit that for these methods *"the generated metadata path and composite form are part of the freeze"*. The omission was deliberate and reasoned — a test asserted it, on the grounds that the manifest "must not guess a portable-registry rendering" — and that reasoning was **correct for its premise**: no released metadata existed, so any rendering would have been hand-authored. F2 is what changed the premise. The layouts are now *resolved from released metadata* by `scale_metadata.surface_layout` (the same function the recorder compares against), cross-checked to be identical across the primary and paired-recovery runtimes, and never typed by hand. The reversal is recorded in the test itself with both premises. Anti-vacuity: forcing `layout_matches: false` on `api.quote` fails the replay suite.
