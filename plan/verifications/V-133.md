## Item

**An empty `node --test` glob exits 0 — every suite in this repo could have silently run nothing**

## Spec ref

15 §4.8

## Status

**found and closed 2026-08-05 during the TypeScript migration**

## Result

`node --test 'tests/x/*.test.js'` exits **0** when the pattern matches no files: `# tests 0`, `# fail 0`, green, and the CI job green above it. Renaming four suites from `.js` to `.ts` emptied `test:mock-runtime` instantly, and the only symptom was a `# pass 0` inside a 900-test run that nobody reads line by line. The hole predates the migration — any rename, move or mis-typed path would have done it. Closed with `tools/run-suite.ts`, which forwards to `node --test`, streams the TAP through unchanged, then **fails when `# tests` is zero or absent**. Absent is treated as zero deliberately: a missing summary line cannot prove anything ran, and an unprovable claim is refused rather than assumed. Patterns now go to **node's own glob** as `*.test.{js,ts}`, so a half-migrated directory keeps running both halves rather than dropping one silently
