## Status

verified 2026-08-14

## Result

The frozen app lock now resolves Lighthouse 13.4.1 through `puppeteer-core` 25.7.0 and
`@puppeteer/browsers` 3.2.0, with neither `extract-zip` 2.0.1 nor the old
`@opentelemetry/core` 1.30.1 path present. PostCSS 8.5.25's `nanoid` dependency is constrained to
the patched 3.3.18 release. Lighthouse 13.4.1 still omits `first-meaningful-paint` from its default
performance audits and retains the published desktop and Moto-G-class preset inputs, so FCP remains
the faithful first-meaningful-render proxy. The required Node floor is 22.19.0; the two CI container
images were independently resolved to immutable linux/amd64 child digests.

Frozen install, app build/typecheck, release build, render-budget and witness runs are green. The
render sample measured desktop FCP at 0.71 s median/tail and mobile at 3.68 s median / 3.69 s tail;
the mobile p50 warning is below the 6 s hard p95 limit and the gate correctly reports it. The full
six-workspace supply-chain gate reports zero npm advisories and passes all RustSec, GHSA-only,
unsound-advisory and npm legs with the repository's existing non-npm waivers still valid.
