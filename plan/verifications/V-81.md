## Item

**`chain-client` exported a type predicate that laundered a forged literal into `Finalized<T>`, defeating the 10 §2.1 brand entirely** (found while starting F3)

## Spec ref

10 §2.1, §4.4; INV-FE-1/9; 15 §2

## Status

verified 2026-08-03, fixed

## Result

`isFinalized(v: Verified<T>): v is Finalized<T>` shipped from the package root at F0. A type predicate **asserts** the phantom field; it cannot check it, because the field has no runtime representation — and that absence is deliberate, it is what makes the design survive structured clone (10 §2.1). So a predicate is a **third mint mechanism**, exactly as powerful as `as Finalized<T>`, and `Verified<T>` lives in the dependency-free `shared-types`, so *every* package can name the input. Measured under the negative corpus's own toolchain: the forged literal `{value, status:{kind:'verified-finalized',…}}` is rejected (TS2322), and the **same literal** through `isFinalized` compiled with **exit 0**. That is 10 §2.1's own stated failure — the guarantee "void silently, with green CI" — and both existing controls were blind to it: the corpus forged a literal *directly*, and `check-finalized-casts.ts` matched `as Finalized<` and `as unknown as` but no predicate. **Fixed three ways:** the predicate is now `hasFinalizedStatus`, narrowing the *status* and returning no brand; 10 §4.4's genuine re-entry need — follower tabs rendering structured-cloned slices the leader broadcasts — is served by an explicit `readmitFromLeader(v, leaderPin)` that is named as the **trust decision** it is (same origin, same release, same TCB per 10 §4.4), takes the leader's pin as an argument rather than reading it off the payload, and refuses any value not already claiming that exact block; and the cast gate now treats `is Finalized<` as a mint. A corpus fixture pins the laundering path shut. Anti-vacuity: all three mint mechanisms re-injected into `packages/verify` and each caught, baseline restored; the corpus's positive control referenced the removed export and **failed loudly**, which is the control doing its job — it was repaired rather than deleted.
