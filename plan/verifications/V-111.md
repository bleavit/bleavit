## Item

**`@vitejs/plugin-react` is not needed, and adding it would have been supply-chain surface for nothing**

## Spec ref

10 §1; 01 §9

## Status

**verified 2026-08-04 by a byte-identical rebuild**

## Result

V-108 read four React pins from the registry, and the plugin was one of them. Vite 8's esbuild transform reads `jsx` and `jsxImportSource` from `tsconfig.base.json` directly, so the plugin has nothing to contribute to a production build with no Fast Refresh and no dev server in the release path. Proven rather than assumed: `release:build` with the plugin removed emits the **same chunk at the same 198,500 bytes and the same content hash**. Dropped from `devDependencies`; `react`/`react-dom` 19.2.8 and the two `@types` pins stand
