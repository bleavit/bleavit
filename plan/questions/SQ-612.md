## Question

**No document names which archive read interface `app/tools/snapshot` binds to, and that — not 10 §4.2 — is what blocks its adapter.** The driver is pure over an injected export and the adapter is unwritten. Its previous park cited §4.2 (*smoldot serves `chainHead` only, no `archive_*`*), which is true and is **not** the reason: §4.2 constrains the light client running inside the browser, while `tools/snapshot` is a Node command-line tool that never loads smoldot and may open an ordinary RPC connection. Four things are unspecified and none is a detail: **(1)** which read interface (`archive_v1_*`, the legacy `state_*`/`chain_*` pair, or an external index — they differ in what a range query even means); **(2)** at which endpoint, and how a producer names it, since reproduce-by-anyone needs an addressing convention rather than a flag; **(3)** what pagination looks like, which decides what the export's `observed` ranges can honestly claim — the tool already refuses an export whose `observed` overstates what a reader saw, and a reader cannot report that faithfully without knowing how the interface signals a short answer; **(4)** which historical-metadata policy applies, since decoding events at depth needs the *producing* runtime's metadata (§6.5) whose retrievability at depth is 10's own open `[VERIFY — FE-P5]`. Answering any by assumption is R-2 fabrication, and getting one wrong produces documents that pass every screen while describing a history that did not happen.

## Status

**resolved 2026-08-07 (F24, 10 §8.5.1)** — ruled under R-1 rather than escalated: all four sub-questions were derivable, and the park misread R-2's ban on *fabrication* as a ban on *deciding*. **(1) Which interface:** the `archive_v1_*` group, because §4.2 already binds the in-browser client to the same specification's `chainHead_v1_*` sibling — one storage model, one key-type vocabulary, one operation/event convention across both readers; the legacy `state_*`/`chain_*` pair carries no versioned contract for a second producer to rely on. **(2) Which endpoint:** none — the question dissolves. Reproducibility is a property of the *document*, so it is addressed by `archive_v1_genesisHash` and by range endpoints pinned with `archive_v1_hashByHeight`, never by a URL, and the shipped format already carries and compares `binding.genesisHash`. **(3) Pagination:** `storageDone` is **not** a completeness proof (V-343) — the interface specification says it follows all storage events and is silent on early termination, caps and discards, so a reader establishes completeness by continuing with `paginationStartKey` until nothing new appears, and records an `observed` span only when every read covering it concluded. **(4) Historical metadata:** via `archive_v1_call` at the block being decoded, and **`[VERIFY — FE-P5]` does not reach this tool** — that gate asks whether the *light client* can reach metadata at depth, and an archive node retains historical state by definition. A block that cannot be decoded is refused, never emitted raw **CORRECTED 2026-08-07, same day, by the R-6 re-review — three claims above are retracted and this cell is where a later session would otherwise copy them.** (a) The `archive_v1_*` binding does **not** follow from §4.2: that section limits the in-browser light client, and `tools/snapshot` is a Node command-line tool that never loads smoldot. The derivation is §8.2's reproduce-by-anyone promise, which is made to second producers, and only a **versioned** contract lets a second producer keep it. (b) The document does **not** pin its range by block hash — §6.3 states that the format *"states no block hash at any block"* and refuses a provider range carrying one, and the shipped `SnapshotRange` is two numbers. `archive_v1_hashByHeight` pins the **reader**, so two producers do not race a reorg. (c) *"An archive node retains historical state by definition"* is an operational expectation, not a specification guarantee, so the metadata-at-depth capability is tagged **[VERIFY — FE-P12]** and its consumer refuses the block rather than assuming retrievability. What survives unchanged: the group choice itself, the endpoint-free addressing, and completeness established rather than inferred.
