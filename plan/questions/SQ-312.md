## Question

**The attestor registry has no cause-carrying removal surface, and SQ-97's dispatch-check relaxation cannot ship without one.** Ordinary queue and dispatch checks therefore both remain on the live roster. Nothing on chain can express "for cause": contract-v9 02 §7.5 freezes `AttestorInfo { account, bond, false_count, active }` and `set_members` takes only a member list. `false_count` is readable, but an attestor discovered unreliable after their 72 h windows closed can never be adjudicated false, so it cannot substitute for a cause. The future remedy is a cause-carrying removal call/field plus per-record revocation event in the next contract revision; B16's already-authorized terminal recovery is a separate exact-byte exception and does not implement SQ-97's ordinary-dispatch relaxation.

## Status

**resolved 2026-07-23 (B19, contract v10).** Added `remove_for_cause(who, cause_hash)`, `AttestationRevoked`, bounded `Revocations`, independent `Liabilities`, and `reap_attestation`. The execute-time relaxation now counts only matured, unrevoked records; queue admission remains live-roster based.
