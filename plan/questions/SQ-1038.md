## Question

**Eight branded types still permit on a payload a spread can replace.** The F17 round-five sweep compiled the claim that object spread preserves a brand, hardened five types with a `#private` marker class, and left eight ranked and unfixed. In the recommended order: **`SpotCheckReport`** (`{...report, findings: []}` skips the refusal, and `{...report, compared: 999, reach: 'whole-document'}` buys the *compared against the chain* badge outright), **`SampledRound`** (same badge by another route), **`FundingReaders`** (`{...readers, assetHub: localReader}` puts futarchy-chain reads under an Asset Hub label — 11 §11.9.1 already names this failure as undetectable by any badge), **`DecodedCall`** (the only checked field is a refusal, so `pallet`, `call` and `args` are free, and the user consents to a description that is not the bytes — 11 §11.3's substitution attack in a new shape), **`CapabilityGrant`**, **`AdmittedSnapshot`** (whose comment reads *\"the brand already proves it\"*, a claim now known false), **`AdmittedRate`**, and **`SelfIngested`/`CoverageRange`** (lowest, since the module already concedes the runtime half and INV-FE-7 keeps the transaction path out of `local-index`). The repair is mechanical and costs nothing at the call sites — the marker is phantom, so all five hardened types needed zero consumer and zero fixture changes. Each needs a fixture that constructs by **spread**, since that is the door both previous checks missed.
