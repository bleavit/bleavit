## Question

05 §5.3's `BaselineCarried` event (Baseline-book-failure carry) is not in the frozen 02 §6 epoch event set; A8 emits it as a pallet-local addition and sources the previous settled Baseline TWAP via a market seam (recent-cohort summaries finalize too late for the decision). Append to 02 §6 at a future contract touch.

## Status

**resolved 2026-07-24.** The event was already correctly frozen in 02 §6, so no contract bump was needed. `pallet-market` now captures the latest valid Baseline full-window TWAP when its exact decision window seals, retains the bounded snapshot alongside `BaselineMarketOf`, and deletes it atomically on market reap. The runtime carry seam reads this immutable snapshot, so a later in-flight window and a late e+3 cohort summary cannot change the value used by the next epoch.
