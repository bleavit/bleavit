## Question

Deployment documentation classifies webhook URLs as credentials, but `post_webhooks` interpolates
the complete URL into every failure log. Tokens in userinfo, path or query therefore enter journald
or centralized logs after an ordinary HTTP/transport failure, giving a log reader the ability to
post false incident or status messages.

## Status

**resolved 2026-08-12.** Webhook failures log only a redacted endpoint label and
sanitized error class; URL userinfo, paths, queries and exception text cannot
enter logs. Tests cover HTTP and transport failures carrying secret tokens.
