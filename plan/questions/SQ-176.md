## Question

**Three guardian powers have no downstream effect endpoint:** `pause_intake`, `activate_playbook`, and `suspend_on_gate`. The guardian core records allowance/playbook state but neither epoch nor the other Track-A pallets expose the required atomic effect/revert calls. Runtime dispatch returns `Err`, rolling back the fifth approval instead of emitting event-only success.

## Status

resolved 2026-07-17 (B1b completion): all five powers dispatch real effects; kernel-enumerated 06 §6.2 playbook routines produce the `EmergencyPlaybook` origin; intake-pause/gate-suspension/freeze endpoints live with kernel expiry bounds; unfed trigger sources + the PB-MIGRATION cursor sub-step remain fail-closed (SQ-233)
