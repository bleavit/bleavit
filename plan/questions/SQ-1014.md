## Question

**`release.json` does not publish the `SOURCE_DATE_EPOCH` the build ran under**, so an independent rebuild under 12 §1.3 can only re-derive it from the source commit. Sufficient while the pipeline derives it that way, and it stops being sufficient the moment an injected value is ever used.
