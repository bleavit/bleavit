## Question

**05 §4.5's five-collator neutralization claim is stated without its phase qualifier, and is false in every phase the chain will actually be in.** "An equal five-collator set scores `D_eff = 1.0`" holds only in phases 0–3: Phase 4 gives **0.960**, Phase 5 **0.933**, Phase 6+ **0.914** — and four equal authors collapse `g(S)` to **zero** in phases 4–7. The unsafe direction is phase advancement without matching set growth, and nothing binds the `n_cap` ladder to the actual set size (`collator.n_target` carries `[VERIFY]`). §4.5's own headline pair reproduces exactly, so the table is right and the sentence over-generalises it. **Conditionally** recorded, because the audit's premise was wrong: 08 §10's "launch volume is zero by construction" is about *trading* volume while `U` counts any non-inherent extrinsic, so launch inertness does not follow unconditionally — but under an explicit persistent-zero scenario the ordering does hold (`U` = 0.25 → `W` = 0 → `Reject(GateVetoSurvival)`, firing **before** the sanity band). The occupancy the S-pillar demands is **12,610 non-empty blocks/day** for the first whole-block decision-grade point; 12,609 still rejects `NotDecisionGrade`. Related: the C-gate's absolute cap binds unconditionally above one bad component-day in 819 under IID, though §4.7 records at most one day per epoch, which raises the analogous threshold to 2.53 % at the two-day minimum
