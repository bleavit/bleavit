## Question

05 §4.8's dead-man recovery epoch is under-specified — it does not define recovery-epoch indexing / deadline re-anchoring or whether recovery also blocks withdrawal / execution callbacks / expiry / guardian transitions. A8 blocks qualify/open_markets/decide/rerun-open during recovery, carries pre-pause `Submitted` proposals into the first post-recovery epoch, and runs exactly one proposal-free epoch.

## Status

**resolved 2026-07-20 (B1 ratification, delegated ruling; corrected 2026-07-20 after Codex P2 review of PR #114).** 05 §4.8 gained a normative *recovery epoch* paragraph. The refused set is stated exactly — `submit`, `qualify`, `open_markets`, `decide`, rerun-open and `settle_cohort` fail with a phase error while recovery is set (the row's list omitted `submit` and `settle_cohort`). **The first ruling over-ratified the open set and was corrected against `epoch-core` before merge:** execution callbacks (`mark_executed`, `mark_failed_executed`, retry exhaustion, `veto_upheld`) and guardian transitions (`delay_once`, `force_rerun`, `schedule_rerun`, vault voiding) carry no recovery guard and are genuinely open, but **withdrawal is categorically closed for the entire recovery epoch** — `withdraw` requires `proposal.epoch == CurrentEpoch` (`crates/epoch-core/src/lib.rs:737`), resume increments the clock so recovery is a fresh index R = P+1 (`lib.rs:608-614`), and `submit` is refused throughout, making that guard unsatisfiable for every proposal; and **expiry is open only in its on-demand form** — the dedicated `expire_or_stale_queue` entry point stays callable, while the automatic `tick` sweep that normally drives it no-ops for recovery's duration (`lib.rs:1430`). Carry-forward is defined by the observed clock (pre-pause `Submitted` proposals re-anchor to whatever epoch the crank observes, so a late crank lands them past recovery+1), and "exactly one proposal-free epoch" is explicitly conditioned on no re-trigger. The G-1 question the correction exposes — whether recovery *should* offer an intake-bond exit rather than deferring it one epoch — is split out as **SQ-285** rather than settled by ratification.
