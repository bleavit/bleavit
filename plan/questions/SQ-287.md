## Question

**Decide-time preimage mismatch slashes 10 %, but 06 §4(5) says constitution violations slash 100 %.** 05 §1.3 names `ConstitutionViolation` as the decide-time producer for a preimage mismatch; 06 §4(5) reads "100 % slash on constitution violation or false resource declaration"; but `crates/epoch-core/src/lib.rs:1094` applies `intake_slash_pct` (10 %, `:123`) to the whole `r == NotDecisionGrade || !guards.preimage_ok` arm, so a decide-time preimage mismatch forfeits 10 %, not 100 %. Which is right is genuinely open. 06 §4(2) already carves preimage-missing *cancellation* (T4, screening) out at 10 %, and the B1 SQ-191 ruling held that 100 % is reserved for a **verified culpable act** — while §7.3 preimage pinning at qualification is specifically designed to make proposer-side unnoting structurally impossible, which argues a decide-time mismatch is an infrastructure failure rather than proposer fault and should slash 10 % or nothing. Options: (a) amend 06 §4(5) to scope 100 % to screening-stage verified violations and name the decide-time mismatch as a 10 % row; (b) raise the code to 100 % for the `!preimage_ok` arm; (c) refund entirely on G-1 grounds. **Pre-existing** — predates and is independent of the SQ-98 fix, which only changes *whether this arm is reached* during a ledger freeze.

## Status

**resolved 2026-07-20 (ratified as shipped; delegated ruling).** The code is right and 06 §4(5) was over-broad; §4 gained a normative scoping paragraph. The 100 % slash covers **screening-stage (T4) *verified*** findings only — a verified constitution violation or verified false resource declaration. A **decide-time preimage mismatch** terminates `Rejected(ConstitutionViolation)` (05 §1.3) but carries rule 2's **10 %**, which is what `epoch-core` applies. Two reasons, the same one twice: confiscation requires a verified culpable act (the B1 SQ-191 taxonomy — every implementation-unverifiable static failure cancels refundably, and rule 2 already prices the preimage family at 10 %); and decisively, 09 §7.3 **pins the preimage at qualification** precisely so the proposer cannot unnote it, making the sabotage window structurally empty — so a mismatch by decide time is an infrastructure or third-party failure, and slashing it in full would punish the one party the pinning design establishes is not responsible. The reason code stays `ConstitutionViolation` (it names *what* failed, not who is culpable); only the disposition is pinned. No code change.
