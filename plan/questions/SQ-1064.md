## Question

`pallet-bleavit-client` refuses `receive_report` once `Reports::count() == MaxReports`, and exposes no
remove, prune, rotate or bounded-ring path. The reference runtime and integration quickstart both
set `MaxReports = 128`. Ordinary report 129 therefore disables push and `OnReport` automation
forever absent a runtime migration. Authoritative proof-backed pull remains available.
