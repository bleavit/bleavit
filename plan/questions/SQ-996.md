## Question

**Doc 12's numeric floors have no cell binder, unlike doc 10 §9's.** `tools/ci/check-frontend-budgets.py` re-derives 59 published cells of 10 §9 from doc 13 and the runtime pin, so a §9 threshold cannot silently disagree with the gate that enforces it. Doc 12 has no equivalent, and it carries at least four enforced numbers: §1.4's floor of **two** distinct active signing keys (`build.ts`), §5.1's floor of **three** independent gateways (`connect-src.ts`, added 2026-08-07), §1.2's **3-of-5** repoint quorum, and 10 §5.4's **≥ 8** browser-reachable bootnodes. Each is held inline beside a citation comment, which is the convention this repository already used and is exactly the shape SQ-557 and the smoldot MiB/MB defect both took — doc and gate each holding the number separately, so neither can notice the other drift. Not urgent: every one currently agrees, verified by reading them. The work is a §12 extractor plus its mutation suite
