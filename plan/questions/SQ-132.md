## Question

**PB-MIGRATION machine-trigger set has three unresolved edges.** (a) Trigger arm 3 "post-upgrade `try-state` assertion failure signal" has **no on-chain signal source** (`try-state` does not run in production block execution) — what is the intended machine-checked source? (b) Does "`try-state` must pass before the freeze lifts" (09 §3.2(3)) bind the on-chain `MigrationHalt` flag or only the guardian playbook freeze? B6 clears migration-source halts on MBM completion / successful recovery-image application without a try-state run. (c) B6 raises the halt on two **non-enumerated** conditions (applied-code mismatch; relay Abort per SQ-131) — conservative, but 09 §3.2's trigger list is closed and should be amended. (d) The normative definition of "cursor **stalled**": B6 uses `(index, inner_cursor)` byte-equality for > `MIGRATION_STALL_BLOCKS` (900); a migration lawfully mutating storage while returning identical cursor bytes would false-raise (self-clears on completion).

## Status
