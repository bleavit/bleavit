## Question

**Unbounded-sentinel semantics:** 09 §5.2's Phase-5 "unbounded sentinels" have no named value in 13 (code uses `u128::MAX`, permitted by the seeded `max`), and this session decided the deposit meter **stops recording** (no reads/writes, always admissible) once the sentinel is installed — the Phase-5 retirement reading; existing entries are retained, not reaped. Name the sentinel in 13 and ratify the retirement semantics?

## Status

resolved 2026-07-20 (batch B6): sentinel named in 13 §1 as the `Balance` type maximum — which is also the seeded hard max, so arming it is an ordinary amendment — with meter retirement and entry retention both ratified
