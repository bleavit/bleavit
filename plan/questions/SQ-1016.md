## Question

**A discharged `[VERIFY]` is still open in two documents.** The Asset Hub asset index is recorded **verified on both target chains** in 02 §8, 02 §7.7 and 11 §11.9.1 (V-17 Polkadot, V-105 Paseo), and `docs/architecture/10-frontend-architecture.md:260` plus `docs/architecture/00-decision-record.md:139` still carry `[VERIFY asset index 1337]`. R-1 requires a resolution to be consistent across the doc set, and this one is not — so a reader of 10 or 00 believes a fact is unestablished that 02 settled. Found while reviewing F26, whose code is clean either way: the index stays an injected `FundingPins` field with no literal.
