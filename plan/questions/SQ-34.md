## Question

`ledger.position_deposit` and `ledger.min_split` are class-META Params tunables with K floors (13 §1), yet the frame-free core (rule 9, no Params access) uses kernel constants. What is the single source of truth for the value used in *both* money movement and accounting?

## Status

**resolved 2026-07-15**: the FRAME pallet is authoritative for the live value — A2 charges/books the deposit from `T::PositionDeposit` for both custody and `DepositsHeld`, and enforces the `transfer` creation floor at `T::MinSplit`; the core's kernel constants are the K floor/backstop only (SQ-25 single-home: K floor in `futarchy-primitives`, live value Config→Params). The other Track-A cores inherit this pattern
