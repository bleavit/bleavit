## Question

`NeutralSettlement.flagged_epochs` is emitted as a constant `1`; 07 §10's "two consecutive flagged epochs ⇒ recompute without the component" rule needs the running consecutive count somewhere. Should the frozen event carry the running count, or does welfare track consecutiveness independently and `1` is fine?

## Status

**resolved 2026-07-15** (user-delegated): **welfare** owns consecutiveness (it owns the `W`-recompute and derives it from the flagged `ComponentValues` history); `flagged_epochs` stays a per-event indicator. 07 §10 amended; no oracle code change.
