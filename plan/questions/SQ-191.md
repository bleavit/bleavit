## Question

**T4 has no slash disposition for residual or implementation-unverifiable static failures.** R2 applies G-1 cancellation plus full refund and reserves 100%/10% for the cases 05 names. The PR #93 fix treats an empty or otherwise class-less payload with an empty resource declaration the same way: it is a verifiable no-op/domain mismatch, but 06 §4 names confiscation only for constitution violations and false resource declarations, so screening cancels and refunds; a class-less payload with a non-empty declaration remains a verified false declaration and is slashed 100%. Confirm the reason/disposition taxonomy.

## Status

**resolved 2026-07-20 (B1 ratification, delegated ruling).** 05 §2.1 gained a normative *T4 disposition taxonomy* note built on one principle: **confiscation requires a verified culpable act**, so every residual, ambiguous or implementation-unverifiable static failure cancels with a full refund (G-1). 100 % slash is reserved for verified constitution violations and verified false resource declarations — including the SQ-191 case of a class-less payload carrying a **non-empty** declaration, and (code-verified) an over-large declaration and a declared-vs-derived footprint mismatch; 10 % to INSURANCE stays scoped to preimage missing/unpinned/oversized; everything else refunds, including the class-less payload with an **empty** declaration, an undecodable payload, an unrederivable call with an admissible footprint, a missing class bond floor, a bond below a floor raised after submission, and a TREASURY ask/in-cap-prize mismatch.
