## Question

**09 §1.1's enumerated queue-time preconditions were incomplete relative to the shipped guard.** Items 1–4 did not include the domain-admissibility check `enqueue` enforces (`domain_allowed(class, domain)` plus the `InternalRootApplyUpgrade` exclusion). **Resolved 2026-07-24:** 09 §1.1 now carries an explicit item 5 requiring preimage-derived domain admission at screening and enqueue, with the narrow Phase-3→4 recovery-image exception bounded by §7.2; 05's decision pseudocode names the same check. The implementation was already enforcing both ends (SQ-308).
