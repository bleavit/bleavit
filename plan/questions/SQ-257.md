## Question

**Constitutional-class proposals are accepted at intake but unfundable at Seed.** epoch-core admits class Constitutional through submit/qualification (bond/lock tuples exist) yet the class has no POL sizing; B10's shrink-to-fit treats its commitment as unavailable, and remediation drops unfundable entries first (minimal-drop). Should intake refuse the class outright (values-track only), or is a defined seed treatment intended?

## Status

**resolved 2026-07-21 (batch X)** — **row premise disproved.** The row read the frame-free core and the Seed planner without following the production shell's earlier bond precondition: a signed Constitutional submission is refused with `BadProposalShape` **before** any custody movement or intake state write, so it can never reach qualification or shrink-to-fit. The core's broader acceptance is defence-in-depth tidiness (an explicit `UnsupportedClass` check would be a nicety), not the claimed production defect.
