## Question

**A proposal that is pre-Executed *and* already decided falls into neither of batch D's cohort-VOID buckets.** 05 §2.1's T20 row covers "any non-terminal **pre-Executed**" proposal, which includes `Queued`, `Suspended`, `Rerun` and `FailedExecuted`. But §2.1's SQ-162 note says T20 applies "only to that epoch's proposals which **have not yet been decided**", and T9 records `Some(Adopt)` on entry to `Queued`. So for that population the two sentences disagree: T20's scope says reject it, the SQ-162 note says it is not T20's business. Batch X wave 1 hit this directly — its first partition preserved these proposals' decisions and two reviewers endorsed that while a third called it a test changed to match a bug. The shipped partition is **cohort membership**, the conservative reading (it changes nothing but the Measuring case SQ-314 named), so the recorded outcome for a VOIDed epoch's `Queued` proposal is `Reject(ProcessHold)` — overwriting a real `Adopt`. Rule which record is truthful. **Related:** 09 §5.2 says the Phase-3 caps are "raised only by phase gates" while 13 §115 says arming a sentinel is an ordinary `set_param` amendment needing "no separate mechanism" — compatible only if the phase-gate raise *is* an ordinary `set_param`. SQ-197's backed-out fix assumed a separate writer that does not exist.

## Status

**resolved 2026-07-24 (ruled + implemented)** — the T20-scope-vs-SQ-162-note contradiction dissolves once `state` and `decision` are read as the different facts they are: the first is the **process** outcome, the second is **what the market concluded**. Ruled: T20's scope is unchanged — every affected non-member is halted, takes `state = Rejected(ProcessHold)`, emits `ProposalForceRejected` and can never execute — but it **MUST NOT overwrite a `DecisionOutcome` already recorded**, writing `Reject(ProcessHold)` only where none exists. Same truth principle batch D ratified for the `Measuring` case (SQ-314): a cohort VOID invalidates measurement inputs, it is not evidence the decision went the other way, and the archive is the only durable record of the market's conclusion. 05 §2.1 and §7(4) amended; `epoch-core` partition, the `pallet-epoch` SQ-314 regression and the runtime `void_cohort` regression updated. This unblocked SQ-197.
