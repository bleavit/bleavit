## Question

**No byte budget measures the stylesheet.** 10 §9.4's row is titled *"Initial JS (critical path, gz)"*, and `check-bundle-budget.ts` enumerates only `<script type="module" src>` and `<link rel="modulepreload">`. F28 adds a render-blocking `assets/[hash].css` that no budget charges — `check:artifact-budget` measures chain-spec and metadata blobs, and `check:budget` is scoped to smoldot's own package. Measured on the first styled build: **8,083 bytes gzipped**, against 2,346,017 for the largest JS chunk, so the stake today is 0.3 % of the critical path and the question is the shape rather than the size — a budget that cannot see a whole file class is the same defect as a check that cannot fail, and a stylesheet is the one asset that grows silently as screens are styled. Two candidate resolutions: widen the §9.4 row from *"Initial JS"* to initial critical-path bytes and teach the gate `link[rel=stylesheet]`, or add a separate CSS row with its own ceiling. The second keeps the existing row's meaning intact and makes a CSS regression legible on its own, which matters because the two grow for unrelated reasons.
