## Question

**11 §11.12's E21 row still reads *"R: disappears on verified Phase ≥ 4"*, which is the numeric comparison §11.10 rules unperformable in the same document.** `PhaseFlags` is a **bitset**, not an ordered number, and the client is correct — `SUDO_PRESENT_BIT = 1 << 4`, with an unread or undecodable value failing closed to `bootstrapPhase = true`. The document contradicts itself and the code is demonstrably right, so this is doc-truing.
