## Question

**`FE-IDX-002` now has a second emitter, and the two failures it would cover are different classes.** SQ-604 asks for the code's definition against **per-range invalidation** — one range the chain disagreed with, dropped, the rest of the index intact. F8's schema migration discards **whole tiers across every range at once**, for a reason that is neither corruption nor disagreement, and the recovery differs: an invalidated range is re-fetchable from layer 2 (§6.2), while discarded chart depth simply re-accumulates. 10 §9.4 requires *"fixed user copy + expert detail + documented recovery per code"*, so one code covering both means one recovery sentence covering both. F8 writes the machine-readable record and deliberately invents no copy. **Ruling needed with SQ-604:** one code, or a third for a migration discard?
