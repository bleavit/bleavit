## Question

**RULED AND EXECUTED 2026-08-04 (R-1) — contract v26 freezes the eight dispatch-check surfaces `execution_guard.execute` reads. SQ-580's defect class, seventh instance.** 11 §11.5 states **13** dispatch-time checks; `rows.ts` encoded **7**, and its test asserted `rowsFor('P-12').length < 13` — passing for a trivial reason. The code comment blamed the 15 §4.8 mirror gate, and **that was false**: `check-dispatch-mirror.py` parses docs 09 §1.2 and 11 §11.5 and **never reads `rows.ts`**. The real obstacle was that seven surfaces were not frozen, so there was nothing to cite and inventing a `SurfaceId` is the hand-listing app-code rule 7 forbids. **The list was derived twice, and each derivation corrected the previous one.** From surface *names*: fourteen items. From `do_execute` itself (`pallets/execution-guard/src/lib.rs:1928-2130`): nine — four dropped because `ledger_freeze_active()` and `dead_man_freeze_active()` read **`Constitution.PhaseFlags`** bits 5/6 and `rerun_held()` reads **`Epoch.Proposals`**, all frozen already (`configs.rs:9402`/`:9411`/`:9416`). From the **metadata**, via `surface_layout()`: **eight** — `Epoch.CurrentEpoch` is not storage at all but a `Get<EpochId>` adapter over `EpochOf::<T>::get().index` (`pallets/epoch/src/lib.rs:459`), so freezing it would have published a surface no metadata contains. Deriving each entry's layout through the same function the checker uses is what caught that, before the checker had to. **Shipped:** 02 **§7.8** (seven `pallet-execution-guard` items) + §7.3 `Capabilities`; `INTEGRATION_CONTRACT_VERSION` 25 → 26; manifest 277 entries; feed, 280 transcripts, 16 descriptors and `critical-surface.ts` regenerated; P-12 now carries **20 clauses covering all 13 checks**, asserted **by surface rather than by count** (a count is satisfied by thirteen copies of the cheapest clause — the original defect inverted). **A doc defect fixed with it:** 11 §11.5 check 9 cited `Epoch.ResourceLocks` where the guard reads `ExecutionGuard.HeldResources` (`lib.rs:2067`); both are real frozen items, so the citation was plausible and wrong. **Two clauses exist for non-obvious reasons and are tested:** `Expedited` is an **exemption** (an expedited proposal executes *through* a freeze, so reading only the freeze flags tells the user they are blocked when the chain would run it), and `GateSuspension` is undecidable alone — `Some(epoch)` is a suspension only when that epoch is current, read with `Epoch.EpochOf`. 3 mutations, all caught. All 24 app gates green; changed-scope Rust gate 476 tests, 0 warnings
