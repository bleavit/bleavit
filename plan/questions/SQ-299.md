## Question

**04 §7a's `q_pol_branch` description does not match the shipped mechanism.** §7a defines the POL exclusion as subtracting "the recorded protocol-seeded position (§10 — the same storage the 'POL undisturbed' check reads)", but `crates/market-core/src/lib.rs:421-425` excludes POL **structurally** — seeding never touches `q_long`/`q_short`, so `q_pol_branch` is identically zero and no storage is read — while the POL-undisturbed check separately keys on `SeededMarkets` and `book.b` (`pallets/market/src/lib.rs:1333-1339`). Same outcome, different mechanism, and the shared-storage claim is false. Code is the conservative and simpler design; true §7a to describe structural exclusion.

## Status

**resolved 2026-07-21 (batch D)** — 04 §7a rewritten: `noi_t = q_long · p + q_short · (1 − p)`, with POL exclusion stated as **structural** (seeding never mutates `q`, so the term is identically zero and no POL storage is read). Both halves of the old claim were false — the subtraction and the shared-storage assertion.
