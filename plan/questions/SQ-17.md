## Question

04 §7's TWAP accumulator "A += o_t·Δblocks" never defines Δblocks: market-core weights the newly recorded (capped) observation backward over the elapsed gap; the reference model weights forward — confirm backward is normative so the model is fixed, not the chain.

## Status

**resolved 2026-07-15** (user-delegated batch; see Decision log): backward weighting confirmed normative — Δblocks = blocks since the previous recorded observation, the new observation covers the interval ending at its record block (04 §7 now explicit); chain/market-core correct, Python model fixed in M3 remediation
