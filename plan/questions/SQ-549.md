## Question

**Phase 0 has no power criterion: a chain that rejects every proposal passes the gate perfectly.** 15 §4.9 gates only the per-class decidable-harm **false-pass** rate, so an always-REJECT policy scores 0 % on all four classes and publishes with `violations: []`. G-1's status-quo default makes that the *cheap* failure mode, not a hypothetical one. The missing half is a decidable-**benefit** false-reject rate (denominator `beneficial ∧ |effect| ≥ δ`, not all beneficial rows) consumed by `normative_violations`. **This is a normative addition to 15 §4.9**, not a test: it changes what a spec-compliant artifact is, so it needs an R-1 amendment and a Decision-log row before any test lands. Deliberately not implemented in S10
