## Question

**`epoch.horizon_k`'s published hard max wedges the chain, and every "× 2 concurrent frozen versions" bound rests on it.** 13 §1 admitted `epoch.horizon_k ∈ [1, 4]` as an ordinary META+values key and `EpochParams::validate` mirrored it (`horizon_k <= MAX_NON_TERMINAL_COHORTS`). Both are wrong by two. A cohort created at epoch `e` measures through `e + k`, settles at `e + k + 1` and is removed only then, so it is non-terminal for `k + 2` epochs; one cohort forms per epoch, so steady state holds `k + 2` live cohorts against I-21's cap of 4. At `k = 3` the fifth concurrent cohort cannot be admitted and **every** `qualify` fails `TooManyCohorts` permanently — a chain-wide liveness wedge reachable by a lawful amendment inside the key's own published bounds, with no warning at the amendment boundary. 05 §3.3 had the arithmetic right all along ("2 measuring + 1 awaiting oracle + 1 settling", "k = 2 (frozen)") and 13 §1 simply contradicted it. The second consequence is quieter and wider: the `≤ 2 concurrent frozen MetricSpec versions` factor in `MAX_ROUNDS = 16 × 4 × 2` (02 §7.2, 13 §4) and in 07 §7's per-version aggregates is *`k`*, so at `k = 4` those bounds were unsound too — four cohorts consuming one measurement epoch can freeze four distinct versions. Surfaced while sizing SQ-141's re-keyed `Aggregates`: the bound I needed to state was not provable from the code that was there.

## Status

**resolved 2026-07-25** — ceiling **derived, not chosen**: `k ≤ MAX_NON_TERMINAL_COHORTS − 2 = 2`, enforced in `EpochParams::validate`, seeded as the constitution row's max, and marked **kernel-bounded** so `amend_registry` cannot raise it back (the wedge is not a tuning choice). 05 §3.3 gained the derivation and the version-bound coupling as normative text; 13 §1's row and rule-7 kernel-bounded set were amended. Consequence pinned in the generated registry suite: with band `[1, 2]` and max-Δ 1 the Δ limit is **unreachable**, so the suite now skips that leg with the proof (`span ≤ delta`) instead of panicking — the first key where max-Δ is vacuous by construction. Two test exemplars that used `horizon_k = 3` to probe the *origin* rule were retargeted to 1 so they keep testing what they were written for.
