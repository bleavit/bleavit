## Question

Is the one 48 h quorum extension budgeted **per `(component, epoch)` lifecycle** (07 §4 "one extension total across all its rounds") or **per frozen version**? With per-version (triple-key) games the `extended` flag lives in each `RoundState`, so two versions of the same `(component, epoch)` each get their own extension — over-budget if the lifecycle reading is canonical.

## Status

**resolved 2026-07-15** (user-delegated): **per frozen-version game** — versioned games are independent tracks, each gets one extension across its own rounds. 07 §4 amended; code already matches.
