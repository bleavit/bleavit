## Question

**Is 15 §4.9's "false-pass rate < 1 %" per class or aggregate?** "Calibrates δ per class to a false-pass rate < 1 %" supports the per-class-each reading, which the G0 checker enforces (`false_pass_rate.{param,trs,code,meta}` each strictly < 0.01 — the strictest reading). Confirm this is the intended S4 artifact shape, including whether TRS gets its own planted-ground-truth class in the simulation.

## Status

resolved 2026-07-20 (batch B6): per-class-each ratified in 15 §4.9 **and** 09 §7.1, with the **decidable-harm** qualifier restored — the row had dropped it, and raw rates (code 1.99 %, meta 2.22 %) would fail a raw reading. TRS sub-question closed: treasury is a real planted-ground-truth class
