## Question

**06 §6.2 Migration row + 09 §3.2(3) contradict the runtime's "no EmergencyPlaybook-safe call" (spec-reviewer major).** SQ-274 confirmed the pinned SDK exposes only Root-only cursor controls, so `playbook_calls(Migration)` provides no guardian-dispatchable effect — yet 06 §6.2 still lists "Admissible call set (exhaustive): … cursor control + resume" and the B1b conformance paragraph asserts every routine "constructs its row's calls". Amend 06 §6.2 + 09 §3.2 to state PB-MIGRATION has no guardian-dispatchable effect (freeze = automatic halt-source bridge; retry/rollback = ratified expedited-CODE lane)? Ties SQ-274/SQ-278.

## Status

**RECONCILED 2026-07-20 (G1, spec-reviewer-verified).** 06 §6.2's PB-MIGRATION admissible-call-set cell + 09 §3.2 amended: no guardian-dispatchable call on stable2606 (cursor controls Root-only, D-13 "nobody"); freeze = automatic `MigrationHalt` execution-queue bridge; retry/rollback = expedited-CODE lane. Matches the runtime's `playbook_calls(Migration)` fail-closed `Err`.
