## Question

**Should a guardian approval that reaches a no-dispatchable-effect playbook revert, or record a `FailedAction`?** Surfaced by drill 06's first real activation (SQ-274): the Migration playbook has no EmergencyPlaybook-safe runtime call (`playbook_calls(Migration)` returns `DispatchError::Other`), so with the trigger active the dispatching 5-of-7 approval **reverts the whole extrinsic** rather than recording a `FailedAction` and succeeding. Reverting is fail-closed (no effect dispatched, no origin widening — R-7) and is what drill 06 now asserts, but it means a legitimately-5-of-7-approved Migration playbook can never reach an activated/recorded state through the guardian path (its freeze arm is the automatic halt-source bridge; its retry/rollback is the ratified expedited-CODE lane). Confirm the revert semantics, or should the pallet record a `FailedAction` for accountability on a no-effect activation?

## Status

**resolved 2026-07-20 (batch B2 · ratified).** The revert stands as fail-closed (no effect dispatched, no origin widening — R-7/G-1), but ratifying it required fixing the sentence it contradicted: 06 §6.2's "**Every** activation emits `PlaybookActivated`, consumes the allowance, writes a review record" was simply **false for one of its own six rows**. §6.2 now scopes that quantifier to effect-dispatching activations and adds the no-effect rule — a playbook row with an empty admissible call set has no dispatchable activation, records nothing, and its accountability path is the automatic `MigrationHalt` bridge and that bridge's event stream, not the guardian review. Verified: PB-MIGRATION is the **only** such row (the other two `playbook_calls` error arms are argument validation already rejected earlier by `BadPlaybookTarget`), and the failing path is production-reachable, not hypothetical. The row's proposed remedy was **not** adopted: a `FailedAction` record already exists in `pallets/guardian` with a different meaning — the review-deadline-miss recall substrate — so reusing the name would have made 5 approvers directly recall-eligible via `guardian.recall` for a no-effect activation.
