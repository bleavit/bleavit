## Question

**`pallet_xcm.claim_assets` needs a 06 §3.3 authority-matrix row.** B10 classifies it Public (09 §6.1 self-scoped Signed reclaim requires it) and proves Treasury-origin dispatch for protocol-keyed traps; 06 §3.3 has no row (only `pallet_xcm.{send, force_*}` → nobody). Add the row (Public, self-scoped by AssetTrap keying) under the S5 inventory discipline?

## Status

**resolved 2026-07-21 (batch D)** — 06 §3.2 gains the `pallet_xcm.claim_assets` row (Signed for self-keyed traps, `FutarchyTreasury` for protocol-keyed), which 09 §6.1 already mandated; the omission was 06's. Verification found the TREASURY leg is **not reachable end-to-end**: the resource-footprint matcher has no `claim_assets` arm, so screening rejects it. Raised as **SQ-316** (batch X).
