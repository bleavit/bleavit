## Question

**`ForeignAssets.create` is classified and origin-gated as ConstitutionalValues but is absent from the bare values-enactment admission set.** The runtime `BaseCallFilter` therefore rejects the call before the pallet can validate its ConstitutionalValues origin, making the configured creation path unreachable. Should the leaf join `is_values_enactment_leaf`, or is its classifier/origin assignment wrong?

## Status

resolved 2026-07-17 (PR #86 remediation round, connector P2): `ForeignAssets.create` joined `is_values_enactment_leaf` (the pallet's `CreateOrigin = EnsureConstitutionalValues` remains the independent second check, 06 §3.3(b)); the ignored regression was activated (scheduler-admissibility + real dispatch: signed → `BadOrigin` at the pallet, values origin → creates) and the values-set equality now permits no exceptions. **The same fix was applied to the sibling instance the S5 suite caught on the A8 merge: `epoch.set_next_epoch_length`** (CV-domain, in-pallet `ConstitutionalValuesOrigin`-gated, was scheduler-unreachable)
