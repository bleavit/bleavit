## Question

VOID cohorts have no normative reap/archive policy — retained terminal `Void` cohort records can accumulate despite I-21's bounded-collection language; and 03 (Baseline settle at `s = 0.5` for epoch VOID) vs 05 (Void cohorts skip settlement) name no owning transition. A8 keeps Void cohorts out of the non-terminal ≤4 bound but does not reap them.

## Status

**resolved 2026-07-20 (code fix; audit scope A).** The 03 §2.3/§5-mandated Baseline settlement is now wired into the epoch-VOID path. `WelfareOps` gained `settle_baseline_void(epoch)` — welfare stays the sole settlement authority (05 §6), epoch may request a settlement but never choose its score — and `void_cohort` calls it in the same transaction that flips the cohort to `Void`. The score is the new single-homed kernel constant `futarchy_primitives::kernel::VOID_BASELINE_SCORE` (0.5). G-1 edges: a new `LedgerSettlement::baseline_open(epoch)` precondition makes "no Baseline vault" and "already settled" silent no-ops so a VOID can never fail on this leg, while genuine ledger errors still propagate rather than being swallowed. Deliberately scoped **out** of the per-proposal `void(pid)` path: T20 vault voiding is a different VOID and the Baseline vault is keyed per epoch. Docs trued in the same change — 03 §5 now names the owning transition and the G-1 no-op rule; 05 §7 gained item (5) distinguishing "a VOID skips welfare *scoring*" from the one settlement it still performs, resolving the 03-vs-05 contradiction the row flagged. **A third defect surfaced and was fixed with it, in `pallet-market`:** `observe_baseline_terminal` latched `SettlementObservedAt` without closing the book, unlike its proposal counterpart `observe_proposal_terminal`, while `do_try_state` requires every observed entry to carry `MarketPhase::Closed` + `ClosedAt`. It was unreachable before this fix — on the ordinary path `close_markets` closes the Baseline book once the epoch's last proposal leaves Trading/Extended — but an epoch VOID force-rejects through `void_cohort` without ever passing through `decide`, so nothing closed it and the new settlement became the first writer to latch on an open book. Fixed by mirroring the proposal path's conditional `close_book`. This is precisely the 03 §9 drift class (try-state violation ⇒ I-4 flag ⇒ PB-LEDGER-FREEZE eligibility under D-9), so a legal `void_cohort` would have armed the emergency brake.
