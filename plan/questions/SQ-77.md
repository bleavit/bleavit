## Question

The three welfare frontend-read items (`Snapshots`/`MetricSpecs`/`GateBreachFlags`) — `StorageMap` or `StorageValue<BoundedVec>`? 05 §4.7 explicitly types `GateBreachFlags: map EpochId → flags`; 02 §7 freezes key/value types; 05 accesses snapshots by epoch key throughout.

## Status

**resolved 2026-07-16** (code): all three implemented as `StorageMap`s keyed by version / (epoch,version) / epoch — matching 05 §4.7's literal map for `GateBreachFlags` and the by-key access pattern for the other two; the FE reads each by its storage-map key. No 02 change (names unchanged; the map shape is what 02 §7's "key/value types" already implied).
