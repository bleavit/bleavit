## Question

**12 §5.1's class-2 ar.io gateway list is empty, and which operators belong is not a values-layer number.** An empty class 2 is not a neutral placeholder: Wayfinder selects the **intersection** of its network-sourced set with this allowlist, so an empty list leaves the client able to fetch release bytes from its own origin alone, and §5.2's out-of-band monitor separately requires resolution across ≥ 3 independent gateways. **The floor is ruled and the membership is not.** Three is §5.2's own figure rather than a new one — a shorter list ships a release this repository's own monitor cannot check — so §5.1 now states it normatively and `connect-src.ts` blocks below it (the check read `length === 0`, so **one** gateway satisfied it, and changing that broke no test). Naming the operators is escalated under R-1's own rule: each entry becomes permanent allowlisted egress for every user of every release carrying it, §5.1 states plainly that exfiltration *to* an allowlisted host is not stopped, no evidence in the specification anchors which operators belong, and the error direction is the unsafe one. The incumbent-baseline diff gate governs every *later* addition and cannot govern the first, because a baseline of zero admits any list at once. Until they are named the list stays empty and `--production` refuses (G-1)

## Status
