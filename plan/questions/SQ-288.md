## Question

**03 §7 R-4 requires the ledger sovereign, treasury sub-accounts and book accounts to be "genesis-endowed and can never be reaped" — no genesis path endows any of them with USDC.** `runtime/bleavit-runtime/src/genesis.rs` registers the USDC and DOT assets and their metadata but sets `accounts: vec![]`, and `deploy/genesis/allocations.template.json` carries no USDC endowments either. Consequence: `pallet_conditional_ledger::settle_collateral` uses `Preservation::Preserve`, so the **last full redeemer of the last open vault** fails with `Token(NotExpendable)` once the sovereign's balance would fall below USDC `min_balance` — a redemption that is legal under 03 §5.3 becomes impossible, stranding the final claimant. Reach is narrow (requires system-wide escrow to drain to zero, so it is a quiet-chain/wind-down condition rather than a steady-state one) but the failure mode is exactly the R-4 clause's purpose. Options: (a) seed the three account classes at genesis per R-4, which also needs the allocations template and the chain-spec validator to carry them; (b) switch the settlement path to `Preservation::Expendable` and let the sovereign be reaped, which contradicts "can never be reaped"; (c) amend R-4 if the endowment is genuinely unnecessary. Found while building the SQ-92 runtime fixtures — those fixtures mint exactly `minimum_balance(usdc_location())` to the ledger account with an R-4 citation, so the gap is worked around in tests, not in production.

## Status

**closed 2026-07-20 — reclassified out of *Spec questions* as milestone B14.** This was mis-filed: it is not a question. 03 §7 R-4 is unambiguous ("ledger sovereign, treasury sub-accounts and book accounts are genesis-endowed and can never be reaped") and the code simply does not implement it, so there is nothing to rule — only work to schedule. Tracked as **B14** with the full failure analysis; the one genuine open sub-question (whether R-4 can even bind *book* accounts, which are created dynamically at Seed rather than at genesis) is carried in that milestone's scope rather than as a standing SQ row.
