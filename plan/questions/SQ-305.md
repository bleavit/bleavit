## Question

**Is `pol.b_baseline`'s omission from the `RederiveBudgets` trigger set deliberate?** B4 added `pol.budget_epoch`, the four `pol.b` class keys and `pol.b_gate` to 13 §5 item 6 but not `pol.b_baseline` — while item 5 explicitly carries the 17,329 USDC Baseline commitment among the derived values item 6 requires re-deriving. 08 §4.3 keeps the Baseline book outside the §4.1 floor arithmetic, which may justify the omission; the doc does not say so. Add the key, or state the exemption.

## Status

**resolved 2026-07-21 (batch D)** — ruled: **add the key**. 13 §5 item 6's trigger set gains `pol.b_baseline` (six POL keys → seven), with the distinction stated: it does not move the §4.1 class floors (08 §4.3 keeps Baseline outside them), but item 6 promises re-derivation of items 1–5 and item 5 expressly carries the 17,329 USDC Baseline commitment.
