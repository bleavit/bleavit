## Question

**Qualification-time preimage ownership has no A8 lifecycle seam.** 09 §7.3 explicitly requires epoch to request the preimage at qualification and release it at every terminal state, but A8 exposes only a length read and A11 cleanup no-ops before a Queue entry exists. The runtime can therefore pin only atomically at successful guard enqueue (and safely unrequest at guard terminal), leaving the normative qualification→queue pin interval and prequeue-terminal release unimplemented without changing the pallet seam. Direct unrequest of an unrequested hash also debug-panics in `pallet-preimage`. Should A8 gain explicit pin/unpin hooks and terminal coverage?

## Status

**resolved 2026-07-17 (B5 review fix):** A8's preimage seam now has idempotent request/unrequest hooks; qualification requests atomically, every pre-queue terminal releases, successful enqueue hands ownership to A11 atomically, and try-state/tests cover orphan/leak prevention.
