## Question

**08 §4.2 requires a NAV-floor refusal to be both an event and an extrinsic error; FRAME can deliver only one.** §4.2 says an arming attempt below floor "fails with `NavFloorUnmet { class, nav, floor }` (event + extrinsic error)". An `Err` reverts the dispatch's storage including `System::Events`, so the two halves are mutually exclusive in one call. SQ-180 shipped the **error** half (`constitution.set_phase_flag` returns `Error::NavFloorUnmet` with `PhaseFlags` unchanged), because leaving the flags unchanged is the fail-static requirement and that needs an `Err`. Consequence: nothing currently emits the loud `NavFloorUnmet` event on the arming path, and `FutarchyTreasury::flag_nav_floor` — the `Ok`-returning loud variant — still has **zero production callers**. Which half is normative? Options: (a) keep error-only and amend §4.2's wording; (b) make arming `Ok`-returning-with-event like §4.4's shrink path, which would mean a refused arming attempt does not fail its extrinsic; (c) emit the event from an `on_finalize`-style path outside the reverted layer.

## Status

resolved 2026-07-22 — **Option (a)**, spec amendment. 08 §4.2 amended: on the *blocking* arming path the loud, durable signal is the extrinsic failure carrying module error `NavFloorUnmet` (`system::ExtrinsicFailed`, or bootstrap sudo's `Sudid { Err(..) }`, 09 §5.4), with the arming bits left unchanged (fail-static) — the reading SQ-180 already shipped, so no runtime-behaviour change. The field-carrying `NavFloorUnmet { class, nav, floor }` event stays available on the non-blocking `flag_nav_floor` diagnostic variant. (b) rejected — a *refused* governance action returning `Ok` weakens the fail-static guarantee SQ-180 adds and surprises the caller (R-7); (c) rejected — machinery for no gain. `NavFloorUnmet` is **not** a frozen 02 §6 surface (02 §6 lists it not-in-ingest, treasury-owned per 08 §1.4), so **no contract bump**. Evidence: `arming_below_floor_surfaces_the_module_error_durably_via_sudo_with_no_pallet_event` (`runtime/bleavit-runtime/src/tests_treasury_health.rs`) pins the durable `Sudid { Err(NavFloorUnmet) }` + unchanged flags + no pallet event. See Decision log 2026-07-22.
