## Question

**SQ-207's code half has no specification to implement against.** B4 ratified the accounting rule (INSURANCE is outside NAV, 08 §1.2) and refused the reachability half to batch X — but the spec never says what the INSURANCE spending path *is*. 08 §1.1 says "inflow-only except by TREASURY decision" and 08 §7.1 justifies routing slashes there rather than burning, yet no `BudgetLine::Insurance` exists, `spend` requires a line, and `recover_foreign` refuses USDC and VIT. Before SQ-207 can be written, 08 must name the intended path: a dedicated budget line, a TREASURY-only sweep to `MAIN`, or an explicit ruling that INSURANCE is a permanent sink — which would require retracting §7.1's anti-burn rationale. Values call.

## Status

**resolved 2026-07-21 (batch D)** — ruled: **`sweep_insurance(amount)`, `FutarchyTreasury` origin, INSURANCE → `MAIN` only**, specified in 08 §1.1/§1.2/§1.4 with the NAV rationale (it is the only operation that raises NAV without an external inflow, so it must be a decided act) and, per B14's R-4, `Preservation::Preserve` semantics. A `BudgetLine::Insurance` was rejected (inverts the direction of every §1.1 control); a permanent sink was rejected (contradicts §1.1 and strands bridged USDC). Implementation remains **SQ-207** in X.
