## Question

**Is a page that fails monotone coverage a correctness finding?** §8.5.2's general rule is *"a liveness failure never reaches the ladder from a read, and a **correctness finding always does**"*, but the only correctness finding it enumerates is a wrong-chain binding, and its error contract makes *"any body that is not a canonical §8.2 document"* a failed read. A document that arrived, parsed, and is **wrong about itself** — movements outside its own declared coverage — falls between the two. The code implements the narrow reading (`rejected`, no ladder effect), which is the conservative one for auto-disable and the permissive one for a source serving malformed pages forever.
