## Question

**03 §11 PT-6's quantifier over-includes `Voided`.** "From every non-`ScalarSettled` state, `void` succeeds" — but `Voided` is non-`ScalarSettled` and `void` from `Voided` must error (03 §2.3 once-rule). Text needs "non-terminal". PT-6 as implemented uses the §2.3 machine and asserts repeat-void errors atomically.

## Status

**resolved 2026-07-21 (batch D)** — 03 §11 PT-6 now quantifies over `Open` and `Resolved` only (`Voided` is terminal, so the old "every non-`ScalarSettled` state" wrongly included it) and states the repeat-`void` and `ScalarSettled` negatives explicitly. The row's claim that PT-6 already asserts repeat-void atomically was **false** — that case is only covered by the generic illegal-op suite.
