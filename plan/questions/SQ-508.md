## Question

**`tools/simulation/run-calibration.py --check` is red on stale provenance, not on economics.** The committed `simulation/results/phase0-calibration.json` was written at `fd2faa0` (2026-07-20); the only differing config key is `source_model_sha256`, because `simulation/src` has since changed in its *validators* and `reference-model/src` in `decision.py`/`treasury.py`/`twap.py`/`welfare.py`. The economics are intact — all **24/24** pinned subsample rows reproduce byte-exactly under HEAD. Pre-existing and **not** caused by E1; recorded because E1 carries an S4 re-run obligation and a session meeting a red `--check` should know which red it is. A `--full` re-run is ~92 min

## Status

**resolved 2026-08-03 (N12) — by regeneration, and the alternative ruling is now clearly the wrong one.** The row offered a shortcut: refresh the digest without re-running, given an argument that the changed sources cannot move an outcome. N12 makes that argument unavailable rather than merely unattractive — it adds a term that *does* move outcomes (the competing-venue diversion), so no blanket "these edits are inert" claim covers the diff, and it adds a whole new artifact block whose numbers only exist if the simulation produces them. The digest was doing exactly the job it was designed for; the stale red was the mechanism working, not a defect in it. Discharged with one `--full` regeneration that serves both this row and N12's own S4 re-run obligation. **Two things the regeneration proves that a digest refresh could not:** the pinned subsample still reproduces byte-exactly under the new sources, and the competing-venue control run reproduces the primary population on the sampled ids (`control_matches_primary`), which is what makes the rungs readable against the artifact at all. Standing lesson for the next session that meets this red: check whether the diff since the artifact contains anything outcome-bearing **before** reaching for a refresh, because the digest cannot tell you and the artifact is the only thing that can
