## Question

`question-service::register` checks both live occupancy and `Questions::count() < MAX_CLIENTS`, where
`MAX_CLIENTS = 64` was derived for the client roster and reused for retained external pairs.
Terminalization decrements live occupancy but retains the question until ledger and market reaping,
which cannot begin until `ledger.archive_delay` (90 days–1 year). A hostile admitted client can run
four 16-question Registered→Voided waves, receive the pre-report fee/escrow back, and leave all 64
retained slots occupied. Honest use reaches the same service-wide outage after 64 questions per
archive horizon. The client admission bond has no slash path and removal does not delete questions.
