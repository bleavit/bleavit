## Question

**The two sibling cranks disagree about emitting on a no-op.** `sweep_redemption_fees` emits `RedemptionFeesSwept { amount: 0 }` on the empty-counter no-op; 04 §2 takes the opposite convention for `sweep_revenue` ("a repeat run is a silent no-op and **exactly one** `RevenueSwept` exists per market"). Harmless on-chain — the keeper rebate is correctly skipped — but two cranks of the same family reading differently is a trap for indexers

## Status

**open** — owner 03; either emit only when `amount > 0` or record the asymmetry deliberately
