## Question

**10 §9.4 enumerates `FE-COMPAT-001..003` and publishes raised-when/recovery text for `003` alone.** A client that must refuse signing on an established-but-unproven runtime therefore has no published code to name, and the tx path reuses `FE-TX-004` — which 11 §11.12 E13 binds to *"a precondition no longer holds — shown as a diff"*, and a compatibility refusal is not that. Choosing 001 or 002 would be guessing at a code's meaning, which R-2 forbids, so the conservative reuse shipped. Should §9.4 publish 001 and 002, or state that the compat refusal on the tx path **is** an `FE-TX-004`? Note the `compat === undefined` sub-case already has a published code (`FE-COMPAT-003`), so at minimum that branch can stop reusing.
