## Question

Treasury custody sync: `fund_budget_line` moves value only inside the internal line ledger, while B9's rebate payouts transfer real USDC from the `KEEPER__`/`ORACLE__` `bl/trsry` sub-account pots — nothing moves custody when a line is funded, so line-ledger vs pot balances can drift (funded line + empty pot = every payout silently skipped; funded pot + empty line = stranded funds). B9 adds the loud alarm (try-state: per payout line, internal balance ≤ pot balance) but NOT the sync mechanism — which is the A9 "asset custody / fungibles" follow-up. Where does custody sync live (fund_budget_line moving USDC between sub-accounts, or a genesis/ops funding convention)?

## Status

**resolved 2026-07-17 (B4-residual)** — 08 §1.4 amended: `fund_budget_line` is custody-synced for the pot-backed lines (KEEPER/ORACLE) via the new `PotFunding` seam — atomic MAIN→pot real-USDC transfer, `Err` rolls back the internal credit; other lines keep custody in MAIN (A9 scope). Try-state drift alarm retained as backstop.
