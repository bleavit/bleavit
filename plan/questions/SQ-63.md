## Question

On the money deadline, `force_neutralize_expired(m)` neutral-settles only *live rounds* for `m` — but an **admitted component that received no report** has no round, so it got no `ComponentValues` entry, contradicting 07 §11(1)'s guarantee that the oracle "guarantees the entry exists by the deadline" (welfare would read an absent component and stall, or settle a cohort without the required neutral value). What supplies the oracle the set of admitted components, which it cannot enumerate from rounds alone?

## Status

**resolved 2026-07-15** (user-delegated, R-1): the epoch/welfare pallet (which owns the cohort→component map, §2(4)) passes the expected `(component, version)` set to `force_neutralize_expired(m, expected)`; the crank writes the neutral flagged carry-last entry for every expected key that produced no round. Added `ReportingContext::expected_components` seam + core no-report path; 07 §11(1) amended; implemented + tested this session.
