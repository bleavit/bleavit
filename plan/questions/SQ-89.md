## Question

The cohort-VOID path (06 §6.2 `epoch.void_cohort`; 03 §2.3 Resolved→Voided during measurement) has no 02 §6 event, and 05 does not state whether cohort proposals also change state. A8 emits `CohortVoided`, transitions each cohort proposal to terminal `Rejected(ProcessHold)` + vault `Voided`, and counts only **non-terminal** cohorts toward I-21.

## Status

resolved 2026-07-21 (batch C, contract v6) — `CohortVoided { epoch: EpochId }` is frozen in 02 §6 under the new inclusion rule (c): a cohort VOID is a terminal cohort transition, and §6's own completeness claim already required an event for it. 05 now states the disposition normatively (every affected measuring/same-epoch live proposal is archived `Reject(ProcessHold)`, emits `ProposalForceRejected`, moves any market-backed vault to `Voided`, and leaves the non-terminal set) and T20's event name is corrected from `ProposalRejected` to `ProposalForceRejected`. Behaviour was already shipped and correct, including the I-21 non-terminal counting.
