## Question

02 §7.4 / 13 §5.1 name the `Markets` storage **value** type `MarketState`, but 02 §4 defines no such struct (its size was `[VERIFY]` until B5 measured `MarketBook` at 189 B, 13 §5.1 / V-27) and `market-core`'s `MarketState` is the whole-state Vec aggregate. A3 stores the per-book `MarketBook<AccountId>` under `Markets` (map name/key/196-bound match 02 byte-for-byte; the FE decodes by SCALE shape, not the Rust type name). Rename the stored value to `MarketState` (renaming the core aggregate), or reconcile 02/13 to `MarketBook` under R-1?

## Status

resolved 2026-07-21 (batch C, contract v6) — 02 §7.4 now names the stored value `MarketBook<AccountId>` (the shipped type) and 13 §5.1's formula follows; the core's `MarketState` stays the whole-state aggregate and was deliberately not renamed, since the FE decodes by SCALE shape. **The row's 189 B is stale** — 13 already records **205 B** as current, with 189 B noted as the superseded B5 measurement.
