## Question

**12 §1.1's recipe requires `SOURCE_DATE_EPOCH` fixed and the app release pipeline never sets it.** `app/tools/release/build.ts` sets no such variable and reads no clock, the SBOM carries neither timestamp nor serial, and two builds at different path depths measured byte-identical without it — so the property §1.1 wants holds **by construction rather than by the control §1.1 names**, which lasts until something starts reading a clock. **Ruled 2026-08-07 (R-1):** set it, derived from the source commit time exactly as `tools/release/build-runtime.sh` already does, honoring an injected value first. §1.1 is **not** amended — it names pnpm, Vite, `dist/` and `sbom.cdx.json`, so it *is* the client recipe and cannot be reassigned to the chain pipeline. `check-release-reproducibility.py` gains a fourth, separately-named refusal for two manifests declaring different values, because a recipe violation arriving disguised as a file diff invites unsetting the variable to make the diff go away. Implementation owed.
