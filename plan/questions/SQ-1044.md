## Question

**02 §9's Phase-3 row reads as an exhaustive enumeration of the deposit-cap precheck's reads, and it cannot express the global cap.** The row says `params()` *"combined with §7.4 `CumulativeDeposits`"*, while 09 §5.2 measures the global cap against **total local USDC issuance** — the runtime's own meter is `ForeignUsdcIssuance = total_issuance(usdc_location())`, that is `ForeignAssets.Asset(USDC).supply`. That item is separately frozen in 02 §8 and is already `storage.identity.usdc_asset` in `CRITICAL_SURFACE`, so reading it is not an excess of the contract. Should the §9 row name it, or state that it enumerates parameter bindings only?
