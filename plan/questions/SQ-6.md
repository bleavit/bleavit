## Question

META+values keys are now enacted by `FutarchyMeta` (06 §1 bars values from parameter keys; values consent = execute-time ratification, 06 §2.2) — but 06 §2.2(b)'s machine-derived rule-altering list does not include `constitution.set_param`, so a META+values `set_param` payload would not be auto-flagged for ratification. Should the list gain it (else the dual consent has no enforcement point)?

## Status

**resolved 2026-07-15** (batch): 06 §2.2(b) rule-altering list gained `constitution.set_param` on META+values-class keys — the dual consent now has its machine-derived enforcement point
