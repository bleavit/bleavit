## Question

**The 07 §4 watchtower liveness sweep has never run: `Oracle::note_epoch_boundary` has no production caller.** The oracle implements it fully — charge inactivity for a just-ended epoch that carried an open round, slash and eject on the **second consecutive** miss, then clear the activity set — and documents it as "the epoch pallet calls this at each epoch rollover (B1a)". Its only callers anywhere are `pallets/oracle/src/tests.rs`. `pallets/epoch::OracleAccess` exposes just `any_open_dispute_touching`, so the rollover hook does not exist. Consequences: a bonded watchtower can miss every acknowledgment forever without charge, ejection or slash, so §4's censorship-repair incentive is unfunded and D-18's bonded-quorum assumption is unbacked; `wt.max`/`wt.quorum` seats are never reclaimed from dead operators, which also makes the unchallenged-closure quorum easier to stall. This is **audit-scope-adjacent stake discipline (R-7)**, not a view gap. It shares the missing seam with SQ-182 and should ship in the same PR: one `OracleAccess` extension, two call sites (rollover, d20), one weight regeneration. Verify while wiring whether `had_open_round` is derivable from the epoch pallet's own schedule/round history as the oracle's doc comment assumes.

## Status

**resolved 2026-07-25 — and the row's closing question had the answer backwards, which was the whole defect.** It asked whether `had_open_round` is derivable from the epoch pallet as the oracle's doc comment assumed. It is not, and an adversarial review caught that my first implementation — derive it in the runtime adapter from rounds keyed to `ended_epoch - 1` — **would have left SQ-491 unfixed while appearing to fix it**: `settle_at` *removes* a cleanly closed round, so in the healthy case no trace survives to the boundary sweep, the predicate reads `false`, and the `!had_open_round` arm **resets** `inactive_epochs`. The charge/slash/eject path would have stayed unreachable in exactly the case where watchtowers had work to acknowledge. Fixed by making it a **latch**: new `Oracle::round_activity` (pallet storage `RoundActivity`) set at the single point a game comes into existence, and `sweep_watchtower_liveness(ended_epoch)` — now one argument — evaluates *(created since the last sweep) OR (a round is open now)* and clears it. The predicate left the seam entirely: a caller-supplied liveness fact is a caller-supplied slash. **Ruled and recorded normatively in 07 §4:** only the most recently ended epoch is swept, and epochs an arithmetic clock catch-up passed over are neither charged nor streak-counted — acknowledgment is not attributed per epoch (one activity set, cleared per sweep), so an epoch whose activity cannot be attributed must not contribute to a slash, and the second consecutive charge slashes and ejects. A swept epoch that carried no round charges nobody and **breaks** the streak. The review also refuted my first justification for that ruling ("a stalled chain offers no block to acknowledge in") — the multi-epoch jump is the chain-alive-nobody-cranked case, where acknowledgment *was* possible — so the ruling now rests on the attribution argument, which survives it. **The Codex review then found that the ruling and the code disagreed.** After an arithmetic catch-up the latch describes the whole interval since the last sweep, not the epoch being swept — a round that opened and closed in epoch 5 would charge idle seats for epoch 8, and a prior miss would turn that into a slash, which is precisely the over-charging the ruling forbids. Fixed by splitting the fact along ownership: the oracle keeps `had_open_round` (a round fact) and the caller now supplies `attributable` (a clock fact it alone can see), and an unattributable sweep consumes the latch and the activity set while charging nobody **and** resetting nothing — an unattributable epoch is neither a miss nor an alibi. At genesis the same expression correctly reads attributable, because `ended = 0` has no predecessor to have missed. A second refinement rode along: the live-round disjunct now excludes money-settled rounds, since §11(1) retains a neutralized round for bond disposal only and a watchtower has nothing left to acknowledge — otherwise retention kept charging for up to eight days after the game ended.
