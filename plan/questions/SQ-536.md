## Question

**`collator.comp_epoch` was 9.44× a published, governance-approved rate for the same role, and pass 1 declined to touch it on the grounds that no evidence anchored it — which was true of this repository and false of the world.** The seed was D-15's 2,000 USDC/collator/epoch, set with no costing behind it. `ops.collators` was **72.6 %** of the post-SQ-531 cost base and it is **standing**, so it alone decided whether break-even needed a full slate (7 occupied slots at τ = 3, above `epoch.slots` = 5 and therefore unreachable) or a single proposal. R-2 reserves escalation for a value whose error direction is unsafe **and** which no evidence anchors; the conjunction was false. **The anchor:** Polkadot OpenGov referendum #1870 (passed, executed) funds 38 system-parachain collators at $250/collator/month, $307.24 fully loaded with the bounty's own hosting/curator/coordinator lines — **211.97 USDC/epoch** at a 21.0-day epoch. **Like-for-like** because a Bleavit collator earns nothing from fees or tips (D-15 burns VIT fees; `OnChargeTransaction`'s `()` drops the imbalance), exactly the reason Polkadot's system parachains are treasury-funded. Reseeded to the **registry minimum 500** (2.36× the anchor); the bound itself is unchanged, so all 20× of headroom is in the safe direction, recovery is ×2 per amendment on a 1-epoch cooldown, and underfunding is fail-soft per 08 §2.4.
