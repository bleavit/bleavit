## Question

**Production genesis seats for the coretime quote authority are ops-ceremony inputs.** B12 wires `coretime_quote_authority`/`coretime_renewal_account` as genesis-set treasury storage (dev presets use the dev ops stand-ins; unset fails closed), but the production genesis-allocation template and chain-spec validator carry no seats for the two values — they are outputs of the Phase-2/3 ops-multisig + Coretime-account ceremony that 09 §4 already `[VERIFY]`-tags. Omission is fail-closed (no quote can be noted, renewal stays inert), so this is an onboarding input, not a safety gap. Add the two fields to `deploy/genesis/allocations.template.json` + validator when the ceremony defines them.
