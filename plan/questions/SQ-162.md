## Question

**Post-measurement cohort VOID has no proposal-machine row.** 05 §7 and 07 §10 allow cohort VOID during measurement (vault `Resolved → Voided` per 03 §2.3), but 05 §2.1 defines no `Measuring → …` transition for it. The S1 model moves only the cohort/vault shadow to VOID and leaves proposal state unchanged.

## Status

**resolved 2026-07-21 (batch D), split.** Doc half done: 05 §2.1 + §7(4) now state that measurement-time cohort VOID is a **cohort/vault** transition with **no proposal edge** and that recorded decisions stand (07 §10) — its absence from the exhaustive table is deliberate. T20's misleading attribution in §7(4) removed (T20 is pre-Executed-only). Verification then found a real defect: `void_cohort` overwrites `proposal.decision` for **Measuring** cohort members and emits `ProposalForceRejected`, destroying decision history (`epoch-core/src/lib.rs:1270-1280`). Raised as **SQ-314** (batch X).
