## Question

**The C_daily renormalized-weight rounding had been load-bearing for bit-identity but stated nowhere normative.** Batch X (SQ-42) fixed a real kernel↔oracle divergence by making the reference model perform the renormalization as an unsigned Q64 quotient, floored, **before** the weighted-log products — the runtime's order. **Resolved 2026-07-24:** 05 §4.4 now defines the 1e9→Q64 conversion and quotient floor explicitly, and 15 §4.4 binds the reference model to that rule.
