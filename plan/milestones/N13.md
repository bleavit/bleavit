**Done 2026-08-03** on the user's scope ruling. Repairs a real hole, not just a scope gap: every other layer already admitted Bleavit accounts into hosted books (`market.buy` is `CallDomain::Public`, `LedgerRoute::for_book` routes with no caller-visible difference, `quote()` already prices them), while 02 alone forbade the client from reading the resulting position — so the client could take a user's money into a book and not show it. **Separate method, not a widened one:** `MAX_ACCOUNT_POSITIONS` is per account **per instance**, so the runtime's own truncation-safety argument is instance-scoped and would silently become false in one shared 64-slot vector. `sp_api` VERSION 2→3; the trait `ID` is unchanged, which is the append-only property. **Codex review round (PR #225) found two follow-on defects, both real and both fixed into v23 rather than deferred:** doc 11's S4 row widened its *reads* to both domains but left its *extrinsics* naming `ledger.*` only, so a hosted redemption would have been addressed to a vault map that never heard of the id (§11.2a rule 5 + the domain-routed S4 column, with the smaller reachable service subset — a hosted question has no gate or Baseline leg); and rule 1 obliged the client to test against `SERVICE_ID_BASE` while 02 §9.4 forbids it a chain literal and no metadata constant published the boundary (`ConditionalLedger::ServiceIdBase`, `#[pallet::extra_constants]`, frozen in 02 §9 + manifest)

<!-- source track narrative -->

Opened 2026-08-01 on the "make the futarchy infrastructure accessible to other parachains,
smart contracts and services via XCM" work order. Bleavit hosts conditional decision markets
for external clients and **sells price discovery, not decisions**: it publishes the conditional
TWAPs with provenance plus a manipulation-cost bound, and the client's own on-chain rule decides
and executes locally. Bleavit never runs foreign code, and no external state reaches any Bleavit
decision, welfare or settlement input. v1 scope by user decision — the spec batch, contract bump
and threat rows land together. Full approved design: `.claude/plans/` (session plan, 2026-08-01).
