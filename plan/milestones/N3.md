Landed 2026-08-01. One arm on `CallDomain`, appended last (SCALE discriminants are positional). Two properties pinned by their own tests: **no governance origin reaches it** (`allowed_for` is false for all eight) and `allowed_for(None) == true` (off-chain services cannot send XCM and use the same calls from a signed account, 16 §2) — the deliberate widening 16 §3.1 states. It **is** exempted from `is_privileged` — an earlier draft had that backwards and the `nested_wrapper_filter` fuzz oracle falsified it in CI within minutes. 06 §3.3 denies "every bare **governance-privileged** leaf" and G-5 defines a privileged effect as one flowing through an enumerated custom origin; this domain needs none, so calling it privileged conflated two properties. Wrapper denial would also have bought nothing: the XCM threat is closed a layer up by `SafeCallFilter ≡ {c : domain(c) == ExternalClient}` (I-35), and a wrapper does not itself classify as `ExternalClient`. The runtime's S5 `matching_origin` match went non-exhaustive on compile — the intended behaviour — and names the new variant explicitly rather than folding it into a wildcard. Gates: `--changed origins-core bleavit-runtime` exit 0 (10 + 418 tests)

<!-- source track narrative -->

Opened 2026-08-01 on the "make the futarchy infrastructure accessible to other parachains,
smart contracts and services via XCM" work order. Bleavit hosts conditional decision markets
for external clients and **sells price discovery, not decisions**: it publishes the conditional
TWAPs with provenance plus a manipulation-cost bound, and the client's own on-chain rule decides
and executes locally. Bleavit never runs foreign code, and no external state reaches any Bleavit
decision, welfare or settlement input. v1 scope by user decision — the spec batch, contract bump
and threat rows land together. Full approved design: `.claude/plans/` (session plan, 2026-08-01).
