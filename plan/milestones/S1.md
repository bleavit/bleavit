Full 10⁶ run green in 50m25s local (CI runtime flagged below). **(3) Ledger↔Python differential** (15 §4.4): 64 seeded op-sequence scenarios (3,032 ops) + score-endpoint + sweep + 10-error-class witness families, single-generator byte-stable corpus (schema v4), exact per-op replay vs `conditional-ledger-core` (full digest) + real-pallet sweep differential across the archive delay (batching, refunds, INSURANCE residue). **Production defects found and fixed by the honest suites**: 4 stale terminal supply decrements in the ledger core (redeem/redeem_scalar_pair/redeem_void/redeem_baseline_pair — Python matched 03 §6, Rust didn't); market-core sell paths merged amount-sized instead of payout-sized (legal sells failed on depleted mirror inventory — Decision log); TWAP lower clamp drifted below the exact (1−κ)^k envelope (directional rounding added — Decision log); zero-payout legal sells + zero-fee buys tripped the ledger's zero-transfer rejection (legs now skipped, deterministic extreme-price regression). Python `_claim_bound` undervalued Voided liability (pair-first valuation fixed). **Process**: 4 parallel authors → dual review (spec-reviewer 0/1/5 + adversarial Codex **5 blockers/12 majors/3 minors, do-not-ship**; two contested blockers adjudicated by the orchestrator against the models by direct inspection) → 4 fix agents + orchestrator surgery (state-explosion view partition, witness wiring, `-metadir`) → focused re-pass **19/20 FIXED, 0 NOT-FIXED**, its 1 new major + 4 minors fixed in-session (incl. honestly deleting a fabricated `WrongBranch` witness — dead core variant, SQ-170). I-27 amended (Decision log); SQ-161…SQ-171; V-30.
