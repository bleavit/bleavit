**The obligation F8 built and could not discharge, owned here rather than absorbed into a neighbour's prose.** `packages/local-index` has **no production consumer**: nothing in `app/src` constructs a `LocalIndex`, so `checkIndexAtBoot` has no call site outside its own suite and every disclosure F8 wrote has a producer and no reader. That is the same defect class F8's own review rounds kept finding one layer down (a checker with no call site; an error code with no emitter; a record on a channel no query reads) and it cannot be closed inside F8, because what is missing is the *client*, not the package. **Explicit obligations, each a thing the user is owed and currently is not told:** `ChartDiscardRecord` — the chart rows a schema migration dropped over blocks `meta.coverage` still claims (this is named because it is the newest and the easiest to lose track of); `PendingRawEvictionRecord` — §6.5 blobs discarded under §9.1's bound; `dropped` and `invalidated` — coverage ranges that did not survive sanitization or the §6.3 edge checks, with their reasons; `unchecked` — ranges nothing could verify, **kept**, which must read as *cannot say* and never as verified; `pendingDecoder` — §6.5's *"N events pending decoder"*; and, on the read path rather than at boot, `CoveredHistory`'s `downsampled` and `chartDiscard` beside every history answer (10 §6.3 *"charts render holes as visible gaps with an explainer, tables state 'complete within [ranges]'"*). **Blocked on copy, not on code:** 10 §9.4 requires fixed user copy plus a documented recovery per error code, and `FE-IDX-002` has no definition (SQ-604) and now two candidate emitters (SQ-783); SQ-820 asks what a tier emptied outright may be *called* and SQ-821 where that fact belongs in a query's answer. So `cannotObserve` is the honest observer rather than a stub, and every range verdicts `unchecked` by construction, which is exactly the set the surface must not drop. **Three arms, because collapsing any two loses the distinction this row exists to make**: `checked`, `not-opened` and `unopenable`.
